# Wiki conventions

- Use canonical terms from `CONTEXT.md`.
- Prefer primary sources: official GitHub documentation and original research papers.
- Distinguish `observed`, `documented`, `inferred`, and `not verified`.
- Keep citations close to claims; use direct URLs in source pages.
- Never turn model confidence into a calibrated probability without held-out evaluation.
- Preserve uncertainty and provenance when summarizing findings or routing owners.
- Append to `log.md`; do not rewrite history to hide stale or conflicting claims.
