# Domain Docs

This is a single-context repository.

Before planning or implementing, read:

- `CONTEXT.md` for canonical domain language.
- Relevant ADRs in `docs/adr/`.
- `docs/wiki/index.md` and linked synthesis pages for research claims, decisions, and caveats.

Keep `CONTEXT.md` a glossary only. Put implementation contracts in the feature spec and durable trade-offs in ADRs. Cite source pages when making claims about GitHub behavior, statistical guarantees, or model evaluation.
